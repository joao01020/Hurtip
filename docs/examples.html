Variáveis e valores

Declaração de variáveis com create e utilização de strings, números e booleanos.

variables.hurtip
Hurtip 
// Meu primeiro programa em Hurtip

// Criando variáveis
create language = "Hurtip"
create version = 1
create age = 24
create is_active = true
create is_finished = false

// Exibindo valores
view(language)
view(version)
view(age)
view(is_active)
view(is_finished)

if / else

Decisões condicionais, operadores lógicos, blocos aninhados e diferentes formatos de bloco.

conditions.hurtip
Hurtip 
// Decisões com if
if (age >= 18) {
    view("Maior de idade")
}

// Decisões com if e else
if (age < 18) {
    view("Menor de idade")
} else {
    view("Maior de idade")
}

// Decisões com operadores lógicos
create has_permission = true

if (age >= 18 and has_permission) {
    view("Acesso permitido")
} else {
    view("Acesso negado")
}

// Decisões com not
if (not false) {
    view("A condição é verdadeira")
} else {
    view("A condição é falsa")
}

// Decisões aninhadas
if (age >= 18) {
    if (age >= 21) {
        view("Idade igual ou superior a 21")
    } else {
        view("Idade entre 18 e 20")
    }
} else {
    view("Menor de idade")
}

// Decisão sem else
create number = 10

if (number == 10) {
    view("O número é 10")
}

// Else em uma linha separada
if (age == 18) {
    view("Tem 18 anos")
}
else {
    view("Não tem 18 anos")
}
Implementado

break e continue juntos

Os dois mecanismos podem ser utilizados dentro do mesmo loop.

control_flow.hurtip
Hurtip 
// Testando break e continue juntos
create control_counter = 0

while (control_counter < 10) {
    control_counter = control_counter + 1

    if (control_counter == 3) {
        continue
    }

    if (control_counter == 7) {
        break
    }

    view(control_counter)
}

view("Control flow finished")

Loops aninhados

Loops podem conter outros loops e blocos de controle.

nested_loops.hurtip
Hurtip 
// Testando loops aninhados
create outer = 0

while (outer < 3) {
    outer = outer + 1

    create inner = 0

    while (inner < 5) {
        inner = inner + 1

        if (inner == 3) {
            break
        }

        view(inner)
    }

    view(outer)
}

view("Nested loops finished")
