01 — Sobre

Uma linguagem em desenvolvimento.

A Hurtip está sendo desenvolvida em C++17 com um interpretador próprio. O projeto possui Lexer, Parser, AST, Interpreter, sistema de módulos e integração inicial com bibliotecas nativas.

◇

Simplicidade

Uma sintaxe direta, pensada para facilitar a leitura e escrita do código.

↗

Versatilidade

Recursos de variáveis, expressões, lógica, controle de fluxo, funções e módulos.

⌘

Extensibilidade

Arquitetura preparada para integração com bibliotecas nativas desenvolvidas em C++.
