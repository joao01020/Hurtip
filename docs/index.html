Linguagem de programação independente

Simplicidade é o começo de novas possibilidades.

Hurtip é uma linguagem de programação experimental desenvolvida com foco em simplicidade, clareza e versatilidade. Um projeto que explora novas possibilidades na integração entre linguagens.

01 — Sobre a linguagem

Uma linguagem construída a partir de uma ideia.

A Hurtip nasceu da vontade de explorar novas possibilidades na programação. Seu desenvolvimento busca equilibrar uma sintaxe acessível com recursos capazes de construir aplicações cada vez mais completas.

◇

Simplicidade

Uma sintaxe pensada para tornar a escrita e a leitura de código mais intuitivas.

⌘

Versatilidade

Recursos de programação que permitem construir diferentes tipos de lógica e aplicações.

↗

Extensibilidade

Uma arquitetura em evolução, com integração a bibliotecas nativas desenvolvidas em C++.

02 — Arquitetura

Do código à execução.

A Hurtip utiliza uma estrutura de interpretação desenvolvida em C++17, transformando o código escrito pelo programador em instruções executáveis.
