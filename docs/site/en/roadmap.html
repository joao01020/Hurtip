Current status

Hurtip already has a functional core developed in C++17, with an integrated Lexer, Parser, AST, and Interpreter.

The language provides variables, expressions, operators, control flow, functions, recursion, scopes, and an initial module system.

The native library import system has also been implemented. Libraries can now be imported by name, use aliases, and call native functions through namespaces. The math library is the first implementation of this system.

The library registration architecture was centralized in standard_library, so main.cpp does not need to register each library individually.

The project has Lexer and Parser unit tests and an automated suite integrated with CTest. There are currently 40 Parser unit checks and 29 tests registered in CTest; all passed in the latest run.

Current development focus

The next goal is to strengthen the reliability of the import system, especially by preventing conflicts between module aliases and native libraries.

After that, development can move forward with expanding the standard library, the API for external libraries, and strengthening diagnostics and stress testing.

Advanced low-level features and support for microcontrollers remain part of Hurtip's long-term vision.
