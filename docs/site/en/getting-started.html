05 — Get started

Take your first steps with Hurtip.

Learn how to access the source code, prepare your environment, and find language examples.

Current status

Hurtip is an experimental project under development. This page provides a starting point for exploring the project and preparing your environment. Check the repository README for specific and up-to-date build and execution instructions.

1. Access the source code

The source code is publicly available on GitHub:

Open Hurtip repository ↗

2. Prepare your environment

The project uses C++17. To work with the source code, you will need a C++ compiler with C++17 support, Git, and CMake, according to the repository's current configuration.

3. Get the project

You can clone the repository with:

git clone https://github.com/joao01020/Hurtip.git
cd Hurtip

4. Check the build instructions

The build structure may change during development. Check the README and the repository's CMake files before running build commands. This ensures that you follow instructions that match the current version of the project.

5. Explore the examples

Hurtip source examples use the .hurtip extension. The examples page presents demonstrations of features available in the current implementation.

View language examples →

As the project continues to evolve, build and execution steps will be documented here once they are stable and documented in the repository.
