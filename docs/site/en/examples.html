Variables and values

Declaring variables with create and using strings, numbers, and booleans.

variables.hurtip
Hurtip 
// My first Hurtip program

// Creating variables
create language = "Hurtip"
create version = 1
create age = 24
create is_active = true
create is_finished = false

// Displaying values
view(language)
view(version)
view(age)
view(is_active)
view(is_finished)

Comparison operators, Boolean logic, and combining expressions.

logic.hurtip

view(not true)
view(not false)

// Combining operators
view(age >= 18 and age <= 30)
view(age < 18 or age == 24)
view(not age > 18)

// Testing logical precedence
view(true or false and false)
view((true or false) and false)

if / else

Conditional decisions, logical operators, nested blocks, and different block formats.

conditions.hurtip
Hurtip 
// Decisions with if
if (age >= 18) {
    view("Adult")
}

// Decisions with if and else
if (age < 18) {
    view("Underage")
} else {
    view("Adult")
}

// Decisions with logical operators
create has_permission = true

if (age >= 18 and has_permission) {
    view("Access granted")
} else {
    view("Access denied")
}

// Decisions with not
if (not false) {
    view("The condition is true")
} else {
    view("The condition is false")
}

// Nested decisions
if (age >= 18) {
    if (age >= 21) {
        view("Age is 21 or older")
    } else {
        view("Age is between 18 and 20")
    }
} else {
    view("Underage")
}

// Decision without else
create number = 10

if (number == 10) {
    view("The number is 10")
}

// Else on a separate line
if (age == 18) {
    view("Is 18 years old")
}
else {
    view("Is not 18 years old")
}
Implemented

continue

Skip the current iteration and continue the loop.

break and continue together

Both mechanisms can be used within the same loop.

control_flow.hurtip
Hurtip 
// Testing break and continue together
create control_counter = 0

while (control_counter < 10) {
    control_counter = control_counter + 1

    if (control_counter == 3) {
        continue
    }

    if (control_counter == 7) {
        break
    }

    view(control_counter)
}

view("Control flow finished")

Nested loops

Loops can contain other loops and control blocks.

nested_loops.hurtip
Hurtip 
// Testing nested loops
create outer = 0

while (outer < 3) {
    outer = outer + 1

    create inner = 0

    while (inner < 5) {
        inner = inner + 1

        if (inner == 3) {
            break
        }

        view(inner)
    }

    view(outer)
}

view("Nested loops finished")

Complete example

This example brings together the features shown above in a single Hurtip program.
