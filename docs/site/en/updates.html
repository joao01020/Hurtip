Ongoing development

This page brings together Hurtip's version history and changes. Its information should reflect the commits, tags, and release notes published in the repository.

Reference version

The project has the v0.1.0-alpha.1 tag, a pre-release version that identifies an early stage of development. As an alpha version, it may include breaking changes, limitations, and features that have not yet been implemented.

Where to follow changes

  • Commits: follow changes made to the source code.
  • Tags and releases: browse identified project versions.
  • Issues: review known problems and proposals under discussion.
