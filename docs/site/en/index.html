01 — About

A language under development.

Hurtip is being developed in C++17 with its own interpreter. The project includes a Lexer, Parser, AST, Interpreter, module system, and initial integration with native libraries.

◇

Simplicity

A straightforward syntax designed to make code easier to read and write.

↗

Versatility

Features for variables, expressions, logic, flow control, functions, and modules.

⌘

Extensibility

An architecture prepared for integration with native libraries developed in C++.

Core syntax

create

Variable creation

The create command creates a variable to store a value and use it in a program.

import

Library imports

The import command imports external libraries to make their functions available in a program.

load

Module loading

The load command loads files and modules that are part of the project itself.
