07 — Contribute

Help build Hurtip.

Find out how to report issues, suggest improvements, and participate in project discussions.

Participate in the project

Hurtip is a project under development. Contributions can help identify issues, improve the documentation, and discuss new ideas. Before proposing changes, get familiar with the repository structure and the current state of the code.

How to contribute

  1. Read the README and learn how the repository is organized.
  2. Check existing issues before opening a new one.
  3. Clearly describe the problem or suggested improvement.
  4. For code changes, keep the scope focused and test what you have modified.
  5. Submit your proposal through GitHub's contribution workflow.

Ways to help

  • Bug reports with steps to reproduce.
  • Improvements to documentation and examples.
  • Tests for existing features.
  • Discussions about syntax, architecture, and libraries.

Repository and discussions

Use GitHub to browse the code, open an issue, or submit a proposed change. Follow the rules and guidelines available in the repository.
