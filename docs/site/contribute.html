07 — Contribua

Ajude a construir o Hurtip.

Veja como relatar problemas, sugerir melhorias e participar das discussões do projeto.

Participe do projeto

O Hurtip é um projeto em desenvolvimento e contribuições podem ajudar a identificar problemas, melhorar a documentação e discutir novas ideias. Antes de propor mudanças, conheça a estrutura e o estado atual do código.

Como contribuir

  1. Leia o README e conheça a organização do repositório.
  2. Verifique as issues existentes antes de abrir uma nova.
  3. Descreva claramente o problema ou a melhoria sugerida.
  4. Para alterações no código, mantenha as mudanças focadas e teste o que foi modificado.
  5. Envie sua proposta para análise pelo fluxo de contribuição do GitHub.

O que pode ser útil

  • Relatos de erros com passos para reproduzir.
  • Melhorias na documentação e nos exemplos.
  • Testes para recursos existentes.
  • Discussões sobre sintaxe, arquitetura e bibliotecas.

Repositório e discussões

Utilize o GitHub para consultar o código, abrir uma issue ou enviar uma proposta de alteração. Respeite as regras e orientações existentes no repositório.
