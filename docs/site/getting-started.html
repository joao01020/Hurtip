05 — Comece aqui

Primeiros passos com Hurtip.

Veja como acessar o código-fonte, preparar o ambiente e encontrar os exemplos da linguagem.

Estado atual

O Hurtip é um projeto experimental em desenvolvimento. Esta página apresenta um ponto de partida para acompanhar e preparar o ambiente. Consulte o README do repositório para instruções específicas e atualizadas de compilação e execução.

1. Acesse o código-fonte

O código-fonte está disponível publicamente no GitHub:

Abrir repositório Hurtip ↗

2. Prepare o ambiente

O projeto utiliza C++17. Para trabalhar com o código-fonte, você precisará de um compilador C++ com suporte a C++17, Git e CMake, conforme a configuração atual do repositório.

3. Obtenha o projeto

Você pode clonar o repositório com:

git clone https://github.com/joao01020/Hurtip.git
cd Hurtip

4. Consulte as instruções de compilação

A estrutura de compilação pode mudar durante o desenvolvimento. Verifique o README e os arquivos CMake do repositório antes de executar os comandos de build. Assim, você utiliza as instruções correspondentes à versão atual do projeto.

5. Explore os exemplos

Os arquivos de exemplo utilizam a extensão .hurtip. A página de exemplos apresenta demonstrações dos recursos disponíveis na implementação atual.
