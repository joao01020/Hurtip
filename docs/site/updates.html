Desenvolvimento contínuo

Esta página reúne o histórico de versões e mudanças do Hurtip. As informações devem acompanhar os commits, tags e notas de versão publicados no repositório.

Versão de referência

O projeto possui a tag v0.1.0-alpha.1, uma versão de pré-lançamento que identifica uma etapa inicial do desenvolvimento. Por ser uma versão alpha, podem existir mudanças incompatíveis, limitações e recursos ainda não implementados.

Onde acompanhar mudanças

  • Commits: acompanhe alterações feitas no código-fonte.
  • Tags e releases: consulte versões identificadas do projeto.
  • Issues: veja problemas conhecidos e propostas em discussão.
